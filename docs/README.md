# Documentação técnica

Decisões arquiteturais, operação local, segurança e auditorias ficam organizadas nesta pasta.

## Hierarquia de referência

Para manutenção atual, use nesta ordem:

1. `AGENTS.md` — regras de execução;
2. `AI_CONTEXT.md` — produto e arquitetura vigentes;
3. `README.md` e `docs/operation/local.md` — execução local;
4. `DESIGN.md` e `docs/design/DESIGN_SYSTEM.md` — direção visual vigente;
5. ADRs e documentos técnicos relacionados à tarefa.

`IMPLEMENTATION_PLAN*.md`, `GOAL*.md`, fechamentos de plano e auditorias de paridade/QA são históricos dos ciclos concluídos. Eles devem ser consultados para rastreabilidade ou retomada explícita, não como backlog atual.
